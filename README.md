# Rohan U — Personal Portfolio

A recruiter-focused React/Vite portfolio for Rohan U.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Important

Replace `public/Resume.pdf` with the actual resume PDF before deploying.

Project GitHub URLs are populated in `src/main.jsx`. Live-demo links can be added later if the projects are deployed.
